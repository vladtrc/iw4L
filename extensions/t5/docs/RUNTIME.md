# T5 runtime policies

Native policies and capture live in `extensions/t5/`. The `ext_t5`
facade registers `Family`; application composition selects the required hooks.

## Map post effects

T5; Shared script blur/DoF; native film and bloom are not selected; Three-band film, bloom curves, persistence and streaks

## Audio codec

Native T5 WMA2 emits budget-owned cached s16 chunks for mono 44.1 kHz and
stereo 48 kHz profiles. WMA seek/tail semantics need corpus validation.
